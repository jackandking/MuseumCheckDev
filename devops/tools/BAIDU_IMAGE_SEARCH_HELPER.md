# 百度图片搜索助手 (Baidu Image Search Helper)

## 概述 (Overview)

百度图片搜索助手是一个免费的浏览器工具，用于帮助您通过百度图片搜索博物馆建筑和文物图片。

**特别优势：** 百度对中国博物馆和文物的搜索结果最全面、最准确，是搜索中文图片资源的首选工具。

## 为什么选择百度图片搜索？

### ✅ 优势

1. **中文搜索最强** - 对中文关键词理解最准确，搜索结果更精准
2. **中国内容最全** - 收录的中国博物馆和文物图片数量最多
3. **图片质量高** - 提供高清大图，适合用于展示和设计
4. **搜索功能强大** - 支持按尺寸、颜色、类型等多维度筛选
5. **相似图片搜索** - 可以基于已找到的图片搜索相似图片
6. **完全免费** - 无需任何API密钥或付费订阅

### ⚠️ 注意事项

- **版权验证必需** - 使用前必须验证图片版权和许可
- **优先选择** - 公共领域、官方网站、知识共享许可的图片
- **手动操作** - 需要手动浏览和复制图片URL

## 使用方法

### 方式1: 直接在浏览器中打开

```bash
# macOS
open tools/baidu-image-search-helper.html

# Linux
xdg-open tools/baidu-image-search-helper.html

# Windows
start tools/baidu-image-search-helper.html
```

### 方式2: 通过HTTP服务器访问（推荐）

```bash
# 启动HTTP服务器
python3 -m http.server 8000

# 然后在浏览器中访问
# http://localhost:8000/tools/baidu-image-search-helper.html
```

## 功能特性

### 🔍 三种搜索模式

1. **搜索博物馆图片**

   - 点击"搜索博物馆图片"

## 工作流程

### 步骤1: 输入搜索信息

```
博物馆名称: 故宫博物院
文物名称（可选）: 清明上河图
```

### 步骤2: 点击搜索按钮

工具会：
1. 生成优化的搜索URL
2. 在新标签页打开百度图片搜索
3. 显示生成的搜索URL供参考

### 步骤3: 在百度搜索结果中

1. 浏览搜索结果
2. 找到合适的图片
3. 右键点击图片
4. 选择"复制图片地址"

### 步骤4: 验证图片

```bash

node tools/verify-treasure-images.js <copied-image-url>

        {
            name: '清明上河图',
            imageUrl: 'COPIED_IMAGE_URL',  // 文物图片
            description: '...'
        }
    ]
}
```

## 图片选择最佳实践

### ✅ 推荐做法

1. **高质量图片**
   - 分辨率 ≥ 800x600 像素
   - 清晰、无水印或水印较小
   - 色彩准确、光线良好

2. **版权合规**
   - 优先选择官方网站图片
   - 查找"可商用"标签
   - 寻找知识共享（CC）许可图片
   - 记录图片来源

3. **内容代表性**
   - 博物馆：外观全景、标志性建筑
   - 文物：清晰特写、细节可见
   - 角度合适、构图美观

4. **URL稳定性**
   - 选择来自稳定域名的图片
   - 避免临时链接或短链接
   - 测试URL可访问性

### ❌ 避免做法

1. 使用有明显水印的图片
2. 使用分辨率过低的图片
3. 使用版权不明确的图片
4. 使用临时或不稳定的URL
5. 未经验证就添加到数据库

## 常见问题

### Q: 百度图片可以直接使用吗？

A: **不可以直接使用**。必须：
1. 检查图片来源网站
2. 查看版权声明和许可协议
3. 优先选择公共领域、官方网站、CC许可的图片
4. 记录图片来源以备查询

### Q: 如何判断图片是否可以使用？

A: 查找以下信息：
- ✅ 来自博物馆官方网站
- ✅ 标注"公共领域"或"Public Domain"
- ✅ 标注"CC0"、"CC BY"、"CC BY-SA"等知识共享许可
- ✅ 明确标注"可商用"
- ❌ 标注"版权所有"或"All Rights Reserved"
- ❌ 有明显商业水印

### Q: 百度vs Wikimedia该如何选择？

A: 
- **需要免费许可** → 选Wikimedia（所有图片都是免费许可）
- **中国博物馆，且没找到** → 选百度（但要验证版权）
- **最安全的做法** → 先试Wikimedia，再用百度补充

### Q: 如何复制图片URL？

A: 
1. 在百度搜索结果中，点击图片查看大图
2. 右键点击大图
3. 选择"复制图片地址"（Chrome）或"复制图像链接"（Firefox）
4. 粘贴到博物馆数据中

### Q: 图片URL失效怎么办？

A: 
- 优先选择来自稳定域名的图片（如官方网站、维基百科）
- 使用verify-treasure-images.js工具定期验证
- 保存图片副本作为备份（可选）

## 技术细节

### URL格式

百度图片搜索URL格式：
```
https://image.baidu.com/search/index?tn=baiduimage&word=<encoded-query>
```

参数说明：
- `tn=baiduimage` - 指定图片搜索
- `word` - URL编码的搜索关键词
