5. Instructions

  1. Check the current priority setting (should be default: tier1-tier2-tier3)
  2. Load a museum (e.g., 首都博物馆) and note the image URL
  3. Upload test data to KV store with a different image URL
  4. Change priority to "Remote Storage → Static Files → Built-in"
  5. Clear cache and reload the museum - it should now use the KV store image
  6. Change priority back and verify it uses the static file image again
