平湖博物馆一页式体验优化方案

❌ 修复前 (Before)

用户流程

1. 点击首页"导览"按钮
访问: single-museum.html?museum=pinghu-museum
2. 显示选择屏幕 ⚠️
- 看到博物馆选择界面
- 看到workflow卡片
- 看到"开始探险"按钮
3. 屏幕闪烁 💥
页面突然跳转
4. 最终显示任务列表
但已经造成困惑

问题分析

function init() { // 1. 初始化选择界面 initSelect(); // 2. 解析URL参数 const mid = getUrlParams().museum; if(mid) onSelectMuseum(m); // 3. ❌ 问题：先显示选择屏幕 setStep('select'); // 4. 然后才检查并跳转 if(hasMuseumParam) { setStep('visit'); // 造成闪烁 } }

用户体验问题

  • ❌ 多余的中间屏幕
  • ❌ 视觉闪烁不流畅
  • ❌ 需要额外点击"开始探险"
  • ❌ 不符合一页式体验预期

✅ 修复后 (After)

用户流程

1. 点击首页"导览"按钮
访问: single-museum.html?museum=pinghu-museum
2. 直接显示任务列表 ✨
- 5个任务一次性可见
- Immersive沉浸模式
- 无导航、无干扰
3. 开始完成任务 🎯
即刻投入，无等待

解决方案

function init() { initSelect(); // ✅ 提前解析URL参数 let shouldSkipToVisit = false; const mid = getUrlParams().museum; if(mid) { onSelectMuseum(m); shouldSkipToVisit = true; // 标记跳过 } // ✅ 根据标记决定初始步骤 if(!shouldSkipToVisit) { setStep('select'); // 只在需要时显示 } // ✅ 直接跳转到visit，无闪烁 if(shouldSkipToVisit) { document.classList.add('sg-immersive'); setStep('visit'); return; // 立即返回 } }

用户体验提升

  • 启动更快 - 无中间屏幕
  • 视觉流畅 - 无闪烁跳转
  • 操作简单 - 无需点击开始
  • 沉浸体验 - 专注任务本身

📍 平湖博物馆 - 镇馆之宝探索工作流

🏛️ 任务列表（5个可见任务）

1. 门口打卡 📸
在博物馆门口拍一张照片
2. 镇馆之宝 1/3 🏺
找到「唐铸铁佛头」并合影
3. 镇馆之宝 2/3 🏺
找到「新石器时代崧泽文化夹砂红陶鼎」并合影
4. 镇馆之宝 3/3 🏺
找到「新石器时代良渚文化黑皮陶盉」并合影
5. 完成合影 📸
和家长比心/拥抱/击掌，留下美好瞬间！

注: 第6个任务"成就海报"在完成后自动显示，不计入任务计数

✨ 一页式体验特性

📜 所有任务可见

5个任务同时显示在页面上，用户可以向下滚动查看完整路线

🎨 状态清晰

当前任务高亮（蓝色边框），已完成半透明，待完成禁用

⬇️ 自动滚动

完成任务后自动滚动到下一个任务，减少手动操作

🔇 沉浸模式

隐藏步骤条、导航按钮、进度条等干扰元素

🔧 技术实现细节

CSS类状态管理

/* 已完成的任务 */ .sg-task-completed { opacity: 0.6; border-color: #d1d5db; } .sg-task-completed::after { content: '✓ 已完成'; background: #22c55e; color: white; } /* 当前任务 */ .sg-task-current { opacity: 1; border-color: #2e7cf6; box-shadow: 0 4px 16px rgba(46, 124, 246, 0.15); } /* 待完成任务 */ .sg-task-upcoming { opacity: 0.5; pointer-events: none; border-color: #e5e7eb; }

Immersive模式CSS

/* 隐藏所有导航UI */ .sg-immersive #sgStepper { display: none !important; } .sg-immersive #step-select { display: none !important; } .sg-immersive #sgVisitPrev { display: none; } .sg-immersive #sgVisitNext { display: none; } .sg-immersive #sgVisitProgress { display: none; }

✅ 修复总结

核心改进：通过优化初始化流程，消除选择屏幕闪烁，实现真正的一页式沉浸体验。

用户价值：点击"导览"后立即看到任务列表，流畅开始博物馆探索之旅。

技术价值：保持所有现有功能完整，仅优化用户入口路径。
