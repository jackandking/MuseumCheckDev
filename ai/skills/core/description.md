# 博物馆打卡助手 — 通用描述

## 产品定位
面向家庭与文博爱好者的博物馆打卡助手，覆盖中国头部博物馆的官方等级查询、镇馆之宝图文介绍、个性化打卡攻略生成。支持亲子场景自动适配，让每一次博物馆之旅都更有收获。

## 核心能力
1. **等级查询** — 查询博物馆官方质量等级（一级/二级/三级）及基本信息
2. **镇馆之宝** — 图文介绍必看藏品，含朝代、类别、简短解读
3. **打卡攻略** — 基于用户兴趣生成 5 任务参观清单，亲子场景自动调整语言和难度

## 目标用户
- 家庭亲子：带娃逛博物馆的家长
- 文博爱好者：想深度了解藏品的参观者
- 旅行规划者：出发前做攻略的游客
