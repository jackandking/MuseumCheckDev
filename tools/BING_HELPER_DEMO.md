# Bing图片搜索助手 - 使用演示

## 🎯 工具介绍

这是一个**完全免费**的浏览器工具，帮助您通过Bing网站搜索博物馆和文物图片，**无需API密钥或任何安装**。

## 📸 界面预览

工具界面包含以下主要部分：

1. **标题区域** - 紫色渐变背景，显示工具名称
2. **搜索表单** - 输入博物馆和文物名称
3. **三个搜索按钮** - 博物馆图片/文物图片/同时搜索
4. **快速搜索** - 常用博物馆的快捷按钮
5. **使用说明** - 详细的操作指南
6. **图片选择建议** - 质量、版权等注意事项

## 📝 使用步骤详解

### 场景1: 搜索博物馆建筑照片

**步骤：**

1. **打开工具**
   - 在浏览器中打开 `tools/bing-image-search-helper.html`

2. **输入博物馆名称**
   - 在"博物馆名称"输入框输入: `故宫博物院`
   - （默认已填充此值，可直接使用）

3. **点击搜索按钮**
   - 点击 🏛️ **"搜索博物馆图片"** 按钮

4. **查看搜索结果**
   - 自动在新标签页打开Bing图片搜索
   - 搜索查询已优化为: `故宫博物院 博物馆 外观 建筑`

5. **选择并复制图片**
   - 浏览Bing搜索结果
   - 找到合适的高清外观照片
   - 右键点击图片 → 选择 **"复制图片地址"**

6. **使用图片URL**
   - 将复制的URL粘贴到博物馆数据的 `image` 字段

### 场景2: 搜索文物照片

**步骤：**

1. **输入信息**
   - 博物馆名称: `故宫博物院`
   - 文物名称: `清明上河图`

2. **点击文物搜索**
   - 点击 🎨 **"搜索文物图片"** 按钮

3. **查看结果**
   - 搜索查询优化为: `清明上河图 故宫博物院 文物 高清`
   - 新标签页自动打开Bing搜索

4. **选择图片**
   - 选择高质量的文物照片
   - 右键复制图片地址

5. **添加到数据**
   - 粘贴URL到 `collections[].imageUrl` 字段

### 场景3: 批量搜索（同时搜索博物馆和文物）

**步骤：**

1. **填写完整信息**
   - 博物馆名称: `中国国家博物馆`
   - 文物名称: `后母戊鼎`

2. **点击批量搜索**
   - 点击 🔍 **"同时搜索两者"** 按钮

3. **多标签页结果**
   - **标签页1**: 中国国家博物馆的建筑照片
   - **标签页2**: 后母戊鼎的文物照片

4. **分别复制URL**
   - 在两个标签页中分别选择和复制图片URL

### 场景4: 使用快速搜索

**步骤：**

1. **点击快速搜索卡片**
   - 界面显示4个常用博物馆卡片
   - 点击任意一个（如"上海博物馆"）

2. **自动填充和搜索**
   - 博物馆名称自动填充为"上海博物馆"
   - 自动执行搜索并打开Bing结果

## 💡 搜索优化说明

### 自动添加的关键词

**博物馆建筑搜索：**
```
用户输入: 故宫博物院
实际搜索: 故宫博物院 博物馆 外观 建筑
```

**文物搜索：**
```
用户输入: 清明上河图 + 故宫博物院
实际搜索: 清明上河图 故宫博物院 文物 高清
```

### 为什么要优化关键词？

1. **提高相关性** - "博物馆 外观 建筑"聚焦于建筑照片
2. **提高质量** - "文物 高清"确保获得高质量文物照片
3. **减少干扰** - 排除不相关的搜索结果
4. **节省时间** - 用户无需手动输入这些关键词

## 🎨 图片选择最佳实践

### 质量标准

**分辨率：**
- ✅ 最佳: 1920x1080 或更高
- ✅ 推荐: 1200x800
- ⚠️  可接受: 800x600
- ❌ 避免: 低于 640x480

**清晰度：**
- ✅ 图片锐利、细节清晰
- ❌ 模糊、失焦、噪点多

**构图：**
- ✅ 主体居中、完整
- ✅ 背景简洁
- ❌ 遮挡、倾斜

### 版权考虑

**推荐来源（按优先级）：**

1. **官方来源** ⭐⭐⭐
   - 博物馆官方网站
   - 政府文化部门网站

2. **开放许可** ⭐⭐⭐
   - Wikimedia Commons
   - 知识共享许可（CC0, CC BY, CC BY-SA）

3. **可信来源** ⭐⭐
   - 新闻媒体报道
   - 教育机构网站

4. **避免使用** ❌
   - 个人博客未授权照片
   - 商业摄影网站带水印图片
   - 版权不明的图片

### 图片格式

**推荐：**
- ✅ JPEG (.jpg) - 照片最常用
- ✅ PNG (.png) - 支持透明背景
- ⚠️  WebP - 较新格式，兼容性略差

**避免：**
- ❌ GIF - 动图，不适合博物馆建筑
- ❌ BMP - 文件太大

## ⚙️ 高级技巧

### 技巧1: 使用英文搜索

对于国际知名博物馆，英文搜索有时效果更好：

```
中文: 故宫博物院 → 结果较少
英文: Forbidden City Beijing → 结果丰富
```

### 技巧2: 组合关键词

如果默认搜索结果不理想，可以手动修改Bing搜索关键词：

```
原始: 故宫博物院 博物馆 外观 建筑
改进: 故宫博物院 正门 红墙 雪景
```

### 技巧3: 使用Bing高级搜索

在Bing结果页面，使用筛选器：
- 📏 **尺寸** → 选择"大"或"超大"
- 🎨 **类型** → 选择"照片"
- 📅 **时间** → 选择"过去一年"（获取最新照片）
- ⚖️  **许可** → 选择"知识共享许可"

### 技巧4: 批量处理流程

为多个博物馆添加图片：

1. 准备博物馆列表（Excel或文本文件）
2. 逐个使用工具搜索
3. 将URL记录在列表旁边
4. 批量复制粘贴到 `museums-data.js`
5. 运行 `npm run validate-data` 验证

## 🔍 故障排除

### 问题1: 打开HTML文件后显示空白

**解决方案：**
- 检查浏览器控制台是否有错误
- 尝试用不同浏览器打开
- 确保HTML文件完整下载

### 问题2: 点击按钮没有反应

**解决方案：**
- 检查是否允许浏览器弹出新窗口
- 查看浏览器设置 → 允许弹出窗口
- 尝试按住Ctrl/Cmd点击按钮

### 问题3: 找不到合适的图片

**解决方案：**
- 尝试简化博物馆名称
- 使用英文名称搜索
- 尝试添加"官方"、"高清"等关键词
- 考虑使用 Wikimedia Commons 工具作为替代

### 问题4: 复制的URL无法访问

**解决方案：**
- 使用验证工具检查: `node tools/verify-treasure-images.js <url>`
- 确保复制的是图片URL，而非网页URL
- 尝试在浏览器中直接打开URL查看
- 如果URL失效，重新搜索其他图片
