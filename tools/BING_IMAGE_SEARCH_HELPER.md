# Bing图片搜索助手

这是一个免费的、基于浏览器的工具，帮助您通过Bing网站搜索博物馆和文物图片，**无需API密钥**。

## 功能特点

✅ **完全免费** - 无需任何API密钥或付费订阅  
✅ **简单易用** - 基于网页的图形界面，无需命令行  
✅ **智能搜索** - 自动优化搜索关键词以获得最佳结果  
✅ **快速访问** - 预设常用博物馆的快速搜索按钮  
✅ **批量搜索** - 可同时搜索博物馆建筑和文物图片  

## 使用方法

### 方法1: 在线使用（推荐）

直接在浏览器中打开：

```bash
# 在项目根目录中
open tools/bing-image-search-helper.html

# 或者用浏览器打开
file:///path/to/MuseumCheck/tools/bing-image-search-helper.html
```

### 方法2: 通过HTTP服务器访问

如果您运行了本地开发服务器：

```bash
# 启动服务器
python3 -m http.server 8000

# 在浏览器中访问
http://localhost:8000/tools/bing-image-search-helper.html
```

## 使用步骤

### 搜索博物馆建筑图片

1. 在"博物馆名称"输入框中输入博物馆名称（如：故宫博物院）
2. 点击 **"搜索博物馆图片"** 按钮
3. 将在新标签页中打开Bing图片搜索结果
4. 浏览搜索结果，找到合适的图片
5. 右键点击图片，选择 **"复制图片地址"**
6. 将URL粘贴到您的博物馆数据中

### 搜索文物图片

1. 在"博物馆名称"输入框中输入博物馆名称（如：故宫博物院）
2. 在"文物名称"输入框中输入文物名称（如：清明上河图）
3. 点击 **"搜索文物图片"** 按钮
4. 将在新标签页中打开Bing图片搜索结果
5. 按照上述步骤复制图片URL

### 同时搜索两者

点击 **"同时搜索两者"** 按钮将自动在两个新标签页中打开博物馆和文物的搜索结果。

## 搜索优化策略

本工具自动优化搜索关键词以获得更好的结果：

### 博物馆建筑搜索
- 查询格式：`{博物馆名称} 博物馆 外观 建筑`
- 示例：`故宫博物院 博物馆 外观 建筑`
- 重点：外观照片、建筑特征

### 文物搜索
- 查询格式：`{文物名称} {博物馆名称} 文物 高清`
- 示例：`清明上河图 故宫博物院 文物 高清`
- 重点：高清图片、文物细节

## 图片选择建议

### 质量要求
- ✅ **分辨率：** 建议800x600像素或更高
- ✅ **清晰度：** 图片清晰，不模糊
- ✅ **格式：** JPEG或PNG格式
- ✅ **文件大小：** 合理的文件大小（< 500KB为佳）

### 版权注意事项

在选择图片时，请注意版权问题：

**推荐来源：**
- ✅ 博物馆官方网站
- ✅ 维基百科/维基共享资源
- ✅ 知识共享许可（CC0, CC BY, CC BY-SA）
- ✅ 公共领域图片

**避免使用：**
- ❌ 有版权的商业图片
- ❌ 带水印的图片
- ❌ 版权不明的图片

### 代表性

选择最能代表博物馆或文物特征的照片：
- 博物馆：选择标志性外观或正门照片
- 文物：选择能清晰展示文物全貌和细节的照片

## 验证图片URL

复制图片URL后，建议使用验证工具检查链接的有效性：

```bash
node tools/verify-treasure-images.js https://example.com/image.jpg
```

## 与其他工具对比

### Bing图片搜索助手（本工具）
- **优点：** 免费、无需API密钥、简单易用
- **缺点：** 需要手动选择和复制URL、无法批量处理
- **适用场景：** 临时搜索、快速查找几张图片

### Wikimedia Commons工具（推荐用于批量）
```bash
node tools/search-museum-images-wikimedia.js "故宫博物院"
```
- **优点：** 免费、自动化、开源许可、命令行批量处理
- **缺点：** 需要Node.js环境、可能结果较少
- **适用场景：** 批量处理、需要明确许可的场景

### Bing API工具
```bash
BING_SEARCH_API_KEY=your_key node tools/search-museum-images.js "故宫博物院"
```
- **优点：** 自动化、结果丰富、可编程
- **缺点：** 需要API密钥、免费额度有限（1000次/月）
- **适用场景：** 大规模批量处理、需要高质量结果

## 工作流程示例

### 完整的图片添加流程

1. **搜索图片**
   ```
   打开 tools/bing-image-search-helper.html
   输入: 故宫博物院
   点击: 搜索博物馆图片
   ```

2. **选择合适的图片**
   - 在Bing搜索结果中浏览
   - 选择高质量、有代表性的图片
   - 注意检查来源和版权

3. **复制图片URL**
   - 右键点击图片
   - 选择"复制图片地址"

4. **验证URL**
   ```bash
   node tools/verify-treasure-images.js https://example.com/image.jpg
   ```

5. **添加到博物馆数据**
   在 `museums-data.js` 中：
   ```javascript
   {
       id: 'forbidden-city',
       name: '故宫博物院',
       image: 'https://example.com/museum-image.jpg',  // 从Bing复制的URL
       collections: [
           {
               name: '清明上河图',
               imageUrl: 'https://example.com/treasure-image.jpg',  // 从Bing复制的URL
               description: '...'
           }
       ]
   }
   ```

6. **验证数据**
   ```bash
   npm run validate-data
   ```

## 故障排除

### 问题：搜索结果不理想

**解决方案：**
- 尝试简化搜索关键词
- 使用英文名称搜索（如：Forbidden City）
- 尝试不同的关键词组合

### 问题：图片URL无法访问

**解决方案：**
- 确保复制的是图片的直接URL，而不是网页URL
- 使用 `verify-treasure-images.js` 工具验证
- 尝试从其他来源查找图片

### 问题：担心版权问题

**解决方案：**
- 优先使用Wikimedia Commons工具
- 查找官方来源的图片
- 使用公共领域或知识共享许可的图片

## 技术细节

### 搜索URL格式

本工具生成的Bing图片搜索URL格式：

```
https://www.bing.com/images/search?q={查询关键词}&form=HDRSC2&first=1
```

参数说明：
- `q`: 搜索关键词（URL编码）
- `form`: Bing表单类型
- `first`: 起始结果位置

### 浏览器兼容性

本工具兼容所有现代浏览器：
- ✅ Chrome/Edge (推荐)
- ✅ Firefox
- ✅ Safari
- ✅ Opera

### 无需安装

本工具是纯HTML/JavaScript实现，无需：
- ❌ Node.js
- ❌ npm包
- ❌ API密钥
- ❌ 网络服务器（可以直接打开HTML文件）
