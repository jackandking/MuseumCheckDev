🎆 导览页面烟花修复测试

问题描述

  1. 完成任务后的奖励动画烟花时间太久（10秒） → 应该缩短到2秒
  2. 完成任务没有在烟花墙上放烟花 → 应该保存到 'museumCheckFireworks' 并上传到远程

测试 1: 检查烟花动画时长

验证 firework.js 中的文本显示时长是否已从 10秒 减少到 2秒

测试 2: 检查 saveFireworkRecord 函数

验证 single-museum.js 中的 saveFireworkRecord 是否保存到正确的 localStorage 键

测试 3: 手动测试指南

  1. 打开导览页面: single-museum.html?museum=forbidden-city
  2. 完成一个孩子任务（点击 ✓ 按钮）
  3. 观察烟花动画是否在约2秒内消失（不是10秒）
  4. 打开烟花墙查看是否有新烟花记录
  5. 检查浏览器 localStorage 是否有 'museumCheckFireworks' 键
