## 🔬 技术亮点

### 迷宫生成算法
- **算法**: 递归回溯 (Recursive Backtracking)
- **复杂度**: O(n²) 其中n为迷宫尺寸
- **保证**: 始终有解，从起点到终点

### Canvas渲染优化
- **性能**: 增量渲染，只重绘变化区域
- **迷雾效果**: 可见半径限制，减少绘制开销
- **响应式**: 根据迷宫大小自动调整画布

### 控制系统
- **多平台**: 键盘 + 触摸 + 鼠标支持
- **防抖动**: 触摸事件防抖处理
- **手势识别**: 滑动方向智能判断
