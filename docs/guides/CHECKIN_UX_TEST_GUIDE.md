## 视觉改进验证清单

### 任务卡片交互 ✨

**测试项**：
- [ ] **悬停效果**：将鼠标悬停在任务卡片上
  - 应该看到卡片向上移动（-6px）并略微放大（scale 1.02）
  - 阴影应该变得更深、更柔和
  - 边框应该变得更亮

- [ ] **点击反馈**：点击任务卡片
  - 应该看到微妙的按压感（scale 0.98）
  - 立即打开任务详情模态框

- [ ] **完成动画**：标记任务为完成
  - 应该看到卡片有轻微的翻转动画
  - 右上角应该出现带"弹出"动画的绿色完成徽章
  - 卡片背景应该变成粉彩渐变

### 进度条动画 📊

**测试项**：
- [ ] **Shimmer 光效**：观察进度条填充
  - 应该看到白色光效从左到右流动
  - 持续循环，不会停止
  - 给进度条增添了生动感

### 按钮反馈 🔘

**测试项**：
- [ ] **主按钮（继续/提交）**
  - 悬停时上升 3px，阴影变深
  - 点击时回到原位，阴影变淡
  - 必须最小 48px 高（触控友好）

- [ ] **副按钮（重置/取消）**
  - 有可见的灰色边框和背景
  - 悬停时背景变浅，略微上升
  - 可视化反馈清晰

### 模态框动画 🎨

**测试项**：
- [ ] **打开模态框**
  - 应该看到从下方向上滑入的动画
  - 背景应该淡入
  - 持续约 300ms，感觉流畅

- [ ] **关闭按钮**
  - 悬停时变成浅灰色背景
  - 点击时有缩放反馈（0.95）
  - 大小足够大，易于点击（48x48px）

### 完成体验 🎉

**测试项**：
- [ ] **完成庆祝屏幕**
  - 应该有背景模糊效果
  - 向上进入的动画，感觉特殊
  - 按钮应该逐个从下方滑入

- [ ] **任务完成 Toast（新增）**
  - 完成任务时，顶部应该显示绿色通知
  - 从上方向下滑入
  - 几秒后自动淡出

## 性能检查

### Chrome DevTools 性能分析

1. **打开 DevTools** (F12)
2. **切换到 Performance 标签**
3. **点击 Record 按钮**
4. **执行**：
   - 悬停任务卡片（1-2 次）
   - 点击打开模态框
   - 标记任务为完成
   - 点击关闭模态框
5. **停止录制**

**预期结果**：
- ✅ 帧率 ≥ 60fps（大多数时间）
- ✅ 没有长任务（> 50ms）
- ✅ 动画帧率稳定

### 动画平滑度检查

```javascript
// 在浏览器控制台运行来检查动画性能
performance.mark('animation-start');
// 执行动画...
performance.mark('animation-end');
performance.measure('animation', 'animation-start', 'animation-end');
console.log(performance.getEntriesByType('measure'));
```

## 移动设备测试

### 使用 Chrome 开发者工具模拟

1. **打开 DevTools**（F12）
2. **点击设备切换按钮**（Ctrl+Shift+M）
3. **选择设备**：
   - iPhone 12（390x844）
   - iPhone SE（375x667）
   - Samsung Galaxy A51（412x914）

### 触控友好性检查

**测试项**：
- [ ] **按钮尺寸**：所有按钮 ≥ 44px
  - 检查：在移动模式下应该轻松点击
  - 不应该有误触发生

- [ ] **间距**：按钮之间的间距 ≥ 8px
  - 检查：不应该有意外点击相邻元素

- [ ] **字体大小**
  - 标题：≥ 28px（移动端）
  - 正文：≥ 14-16px
  - 都应该清晰易读

### 响应式布局检查

**测试项**：
- [ ] **小屏幕（< 480px）**
  - 任务卡片排成 2 列
  - 所有元素应该适应屏幕
  - 没有水平滚动

- [ ] **中等屏幕（480-768px）**
  - 任务卡片排成 2-3 列
  - 模态框应该有合适的宽度
  - 按钮应该可轻松点击

- [ ] **大屏幕（> 768px）**
  - 任务卡片可显示多列
  - 最大宽度 800px（读取舒适）
  - 桌面端用户体验优化

## 报告问题

如果你发现任何问题，请检查：

1. **浏览器控制台**（F12 > Console）
   - 是否有任何 JavaScript 错误？
   - 是否有警告？

2. **网络标签**（F12 > Network）
   - 所有资源是否都加载成功（200）？
   - 是否有失败的请求（404/500）？

3. **样式计算**（F12 > Elements > Styles）
   - CSS 规则是否被应用？
   - 是否有冲突的样式？
