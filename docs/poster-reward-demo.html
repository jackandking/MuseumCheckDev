🔧 技术实现

系统通过事件驱动架构实现海报奖励：

// 1. 海报发布成功后触发事件 EventBus.getInstance().emit('poster:published', { posterId: recordId, title: title, imageUrl: safeImageUrl, userId: userName, museumId: museumId, timestamp: Date.now() }); // 2. PetRewardManager监听事件并发放奖励 this.eventBus.on('poster:published', (evt) => { this.rewardForPoster(evt); }); // 3. 奖励方法 rewardForPoster({ posterId, title, points = 100, userId, timestamp = Date.now() } = {}) { const reward = { type: 'poster', posterId, title, points, userId, timestamp }; this._recordReward(reward); this.eventBus.emit('pet:xp:added', reward); return reward; }
