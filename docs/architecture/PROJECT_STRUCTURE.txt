🚀 QUICK START
═══════════════════════════════════════════════════════════

测试独立游戏:
  open http://localhost:8000/games/tank-battle.html
  open http://localhost:8000/games/space-invaders.html
  open http://localhost:8000/games/snake.html

集成到museum-checkin.html:
  1. 编辑 museum-checkin.html
  2. 在 <head> 添加: <script src="js/game-launcher.js"></script>
  3. 在应用中初始化: const launcher = new GameLauncher();
  4. 添加启动按钮: launcher.launchGame('tank-battle');
