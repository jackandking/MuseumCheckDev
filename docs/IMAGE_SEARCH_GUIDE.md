# 博物馆图片搜索使用指南

## 概述

博物馆数据管理界面现已集成 Wikimedia Commons 图片搜索功能，让您可以轻松找到并选择博物馆和文物的照片，无需在命令行和网页之间切换。

## 功能特点

- 🔍 **可视化搜索**：直接在网页界面搜索图片
- 🖼️ **缩略图预览**：在选择前查看图片
- 🎯 **一键填充**：点击图片自动填充 URL
- 🆓 **完全免费**：使用 Wikimedia Commons 的免费图片
- ⚖️ **自由授权**：所有图片均为公共领域或自由许可

## 使用方法

### 搜索博物馆建筑照片

1. 在博物馆数据管理页面填写博物馆名称（如"故宫博物院"）
2. 在"主图URL"字段旁点击 **🔍 搜索图片** 按钮
3. 搜索框会自动填入博物馆名称
4. 点击 **🔍 开始搜索** 按钮
5. 浏览搜索结果的缩略图
6. 点击喜欢的图片，URL 会自动填充到字段中
7. 模态框自动关闭

### 搜索文物藏品照片

1. 点击 **➕ 添加馆藏** 按钮添加一个文物
2. 填写文物名称（如"清明上河图"）
3. 在该文物的"图片URL"字段旁点击 **🔍 搜索图片** 按钮
4. 搜索框会自动填入文物名称
5. 点击 **🔍 开始搜索** 按钮
6. 浏览并点击选择合适的图片
7. URL 自动填充，模态框关闭

## 搜索技巧

### 中文搜索
直接使用中文名称搜索，系统会自动尝试多个查询变体：
- 博物馆名称
- 博物馆名称 + "building"
- 博物馆名称 + "exterior"

### 英文搜索
对于知名博物馆和文物，系统会自动添加英文查询：
- 故宫博物院 → "Forbidden City Beijing"
- 清明上河图 → "Along the River During Qingming Festival"

### 常见问题

**Q: 为什么搜索不到结果？**
- 尝试使用更通用的名称
- 尝试使用英文名称
- 检查拼写是否正确
- 某些较小或新建的博物馆在 Wikimedia 可能没有图片

**Q: 为什么看到"未找到相关图片"？**
- Wikimedia Commons 可能没有该博物馆/文物的照片
- 尝试使用命令行工具 `tools/search-museum-images-wikimedia.js`
- 可以使用其他图片来源（需注意版权）

**Q: 为什么搜索被阻止（ERR_BLOCKED_BY_CLIENT）？**
- 浏览器扩展（如广告拦截器）可能阻止了请求
- 尝试禁用广告拦截器
- 尝试使用其他浏览器
- 可以使用备选的命令行工具

## 备选方法：命令行工具

如果网页搜索遇到问题，可以使用命令行工具：

```bash
# 搜索博物馆照片
node tools/search-museum-images-wikimedia.js "故宫博物院"

# 搜索博物馆和文物照片
node tools/search-museum-images-wikimedia.js "故宫博物院" "清明上河图"
```

然后手动复制 URL 到网页界面。

## 图片许可说明

Wikimedia Commons 的所有图片都采用自由许可：
- **公共领域（Public Domain）**：可自由使用
- **CC0**：创作共用零版权声明
- **CC BY-SA**：知识共享署名-相同方式共享

使用这些图片是安全的，无需担心版权问题。

## 最佳实践

1. **优先选择高分辨率图片**：查看图片尺寸，选择至少 800x600 的图片
2. **检查图片相关性**：确保图片确实是所需博物馆或文物
3. **验证 URL**：选择后可以在浏览器新标签页打开 URL 确认
4. **保存前预览**：使用"👁️ 预览"标签查看最终效果
